# Wesley Boland, MD

Personal website. Static HTML and CSS, no build step.

- `index.html`: homepage
- `writing/`, `projects/`, `research/`: section pages
- `assets/style.css`: all styles
- `sitemap.xml`, `robots.txt`: search engine files

## Deploy on GitHub Pages

1. Open the repository on GitHub, then Settings, then Pages.
2. Under "Build and deployment", choose "Deploy from a branch".
3. Select the branch that holds these files and the `/ (root)` folder. Save.

The site goes live at https://wesleysnipes13.github.io/wesboland/.

If the address changes (custom domain or a renamed repository), replace
`https://wesleysnipes13.github.io/wesboland/` in the four HTML pages, `404.html`,
`sitemap.xml`, and `robots.txt`.
